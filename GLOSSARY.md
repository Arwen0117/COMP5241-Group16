# Learning Platform

This glossary defines the shared language for identity, course access, and learner records across the learning platform.

## Identity and access

**Learner**:
A person who accesses course content and builds learning records.
_Avoid_: Student

**Instructor**:
A person who owns courses and can manage their enrolled learners and course analytics.
_Avoid_: Teacher, author

**Course**:
A published or unpublished collection of lessons and activities owned by an instructor.

**Enrollment**:
A learner's membership in a course, including whether that membership currently grants access.
_Avoid_: Registration

**Invitation**:
A course-bound, expiring request that a learner can accept after authenticating.

## Learning records

**Learning event**:
A typed record of a learner's learning activity, such as completing a lesson or spending active time.
_Avoid_: Activity log, event total

**Completion**:
An explicit learner or activity completion event that marks a required learning unit as finished.

**Active learning time**:
The bounded duration attributed to authenticated learning activity.
_Avoid_: Time spent total

**Progress**:
The proportion of required learning units with an explicit completion record.

**Score summary**:
The current performance view calculated from the latest valid scored attempt for each activity.
_Avoid_: Average score
